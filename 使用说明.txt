暖心对话助手

【从 GitHub 下载后（2 步即可）】
  1. 编辑 .env：填 DEEPSEEK_API_KEY（没有 .env 就双击「配置DeepSeek.bat」）
  2. 双击「run.bat」
     首次会自动联网准备内置 Python（约 1～3 分钟，只需一次）

【日常】
  启动：run.bat
  停止：关掉黑色窗口；端口占用再运行 stop_server.bat

【文件夹说明】
  runtime\     内置 Python（首次 run 自动生成，勿删）
  app\ static\  程序
  data\        本机对话数据（不上传 GitHub）
  .env         你的 API 密钥（不上传 GitHub，勿发给别人）

【可选】
  setup.bat / build_portable.bat  仅准备环境、不启动服务
